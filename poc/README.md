# poc/ — 현장 실증(PoC) 재료

소방 쪽에 들고 갈 PoC 자료를 만드는 폴더. **승인 0명·환자 데이터 0건으로 만들 수 있는 것**만
여기 둔다.

## 운영 규칙 (`sim/`·`spider/`와 같다)

**다른 폴더의 기존 파일을 수정하지 않는다 — `poc/` 아래 새 파일만.** `info/` 쪽은
데이터 파일 읽기와 어휘 모듈(`hospital_score.vocabulary`) 읽기 전용 import만 한다.
통째로 지워도 다른 브랜치에 영향이 없다.

## PoC 3단 구성

| 단계 | 필요한 승인 | 내용 |
|---|---|---|
| **0단 — 리플레이** | **0명** | 이미 쌓인 공개 데이터를 되감아 "무엇을 알 수 있고 무엇을 알 수 없는지"를 보인다. 아래 리포트 |
| 1단 — 섀도 | 구급대 팀장 구두 | 업무 절차를 바꾸지 않고 추천만 기록. 환자 식별정보 없음 |
| 2단 — 실사용 | 소방본부 + 병원 | 동시 전달. 1단 숫자가 나온 뒤 |

0단이 1단 허락을 받기 위한 재료다.

## 진주 존 리플레이 리포트

```bash
conda activate dev
cd poc && python build_jinju_replay.py     # API 호출 0회
```

산출물 `out/jinju_replay.html` (자가완결 · 외부 의존 없음 · 라이트/다크 · 인쇄 가능).
스냅샷이 더 쌓이면 다시 돌리는 것만으로 숫자가 갱신된다.

### 왜 진주인가

경남 48곳 중 **진주 8곳만 반경 5km 안에 서로 다 들어온다**(28쌍 중 27쌍, 중앙 1.86km).
동시 전달을 실증할 수 있는 최소 단위가 여기서 성립하고, 권역응급의료센터(경상국립대병원)가
존 안에 있으며, 진주소방서 구급차 10대는 경남 공동 1위다.

### 리포트가 말하는 것 (2026-08-12 ~ 10-12, 병상 폴링 2,984회)

1. **병상은 병목이 아니다** — 만실·과밀 비율 최대 2.4%. 폴링마다 값이 28~50% 바뀌어
   실시간 연동도 잘 되고 있다. ⚠ 그래서 **"E-Gen 병상은 낡아서 못 믿는다"로 피치하면 안 된다** —
   이 데이터가 그 반대를 증명한다.
2. **비어 있는 건 "이 환자를 받을 수 있는가"다** — 중증질환 신고 168칸 중 122칸(73%)이
   정보미제공, 2곳은 실시간 피드 자체가 없다.
3. **그 공백을 심평원이 설명한다** — 피드 없던 2곳은 응급의학과 전문의 0명에 정형외과·신경외과
   중심 병원이다("미상"이 아니라 "역량이 얇다"). 응급의학과 전문의 3명 이상은 8곳 중 3곳뿐인데
   E-Gen 화면에서는 8곳이 모두 같은 "응급의료기관"으로 보인다.
4. 그 3곳이 막히면 다음 응급의료센터는 **직선 42km 밖**이다.

→ 그래서 측정할 것은 "병상을 잘 찾았는가"가 아니라 **"받아줄 곳에 처음부터 걸었는가"**다.
리포트 5절에 섀도 PoC 설계·지표 4종·실패 기준이 들어 있다.

### 집계 주의

- 중증질환은 본 항목 `MKioskTy1~28`만 센다. 영유아 5항목의 동반 `...Msg` 칸에 "불가능"을
  적어 둔 병원이 있어 **공백 비율은 보수적으로 높게 잡힌 값**이다(섞어 세면 수치가 어긋난다).
- 응급실 `hvec`의 `-1`은 미입력이 아니라 과밀 1명으로 읽는다(info `egen/mapper.py`와 같은 규칙).
- 전문의 수는 보유 인원이고 특정 시각의 당직이 아니다. "역량이 얇다" ≠ "수용 불가".
- 어휘는 `hospital_score/vocabulary.py` 정본을 import 한다. 손으로 다시 옮겨 적지 말 것.

## 임상 자문 ↔ 실측 수렴표 (`CLINICAL_CONVERGENCE.md`, 2026-10-22)

응급의학과 전문의 서면 자문(12문항)의 결론과 우리가 이미 측정해 둔 수치가 겹치는 항목만
모은 문서. **자문이 방향을 주고 우리가 크기를 줬다**는 구조로만 쓴다 — 자문은 정성적
판단이고 수치가 하나도 없으므로, 자문을 우리 수치의 근거로 인용하지 않는다.

수렴한 7개 항목(전부 재검증 완료):

| # | 내용 | 대표 수치 |
|---|---|---|
| 1 | 경증 분산은 중증 수용을 늘리지 않는다 | 경증 회피를 최대로 올려도 KTAS 1·2 거절 **0~7%**만 감소, 경증은 **+1.6~3.2분** |
| 2 | 상급 역량 이득(μ)은 아직 가정 | 센터 비율 **65.8 → 99.5%**의 대가는 KTAS 1·2 중앙 **+6.8분** |
| 3 | 자동 재배정·양보는 해롭고 재투척만 값을 한다 | τ 창 켜면 거절 **+10.9~16.1%** / 재투척은 **−10~53%** |
| 4 | 미선택 병원 통보 = 배정·거절 공유 | 배정을 공유 안 하면 거절 **+12~72%**, 거절만 공유해도 대부분 회복 |
| 5 | 만실은 한 번 보이면 오래 간다 | 센터 1시간 뒤 **70~80%**, 2시간 뒤 **61~72%** 만실 |
| 6 | 병상 숫자는 바뀌지만 만실로는 거의 안 간다 | 달라짐 **54.2%** · 3석 이상 6.9% · **도착 때 만실 0.84%** (21,250건) |
| 7 | 신뢰도 %를 말로 바꿀 근거 | 조건부 폴링 채점은 밴드 격차 **34%p**, 무작위 표본 채점은 **8%p**뿐 |

같은 문서 §8이 **자문 편지에 쓴 숫자 5개의 대조 결과**다(4개 확인, "94%→100% / 8→12분"은
일치하는 기록이 없어 교정 필요). §3-3은 그 결과로 바뀐 설계 결정 — **τ 창 한도를 차단에서
표시로 내리고 수용 판단은 병원에 남긴다.**

## 차트 규칙

색은 dataviz 기준을 따랐다. 등급은 순서가 있는 값이라 범주형이 아니라 **단일 색 순서 램프**를
쓴다 — `#86b6ef → #3987e5 → #256abf → #104281` (라이트), 검증 통과 기록:
`validate_palette.js "#86b6ef,#3987e5,#256abf,#104281" --mode light --ordinal` → ALL PASS.
지도 산점도는 **쓰지 않는다** — 90m 떨어진 두 곳이 완전히 겹쳐서, 1차원 거리 막대로 바꿨다.
