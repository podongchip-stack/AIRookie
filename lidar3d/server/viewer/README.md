# 3D 뷰어

`scene_mesh.ply`를 브라우저에서 회전/확대하고, 분류별로 켜고 끄고,
**두 점을 클릭해 미터 단위 거리를 재는** 뷰어.

## 지금 바로 확인하기 (폰도 서버도 필요 없음)

```bash
cd server/viewer
python3 -m http.server 8080
```

브라우저에서 **http://localhost:8080** → **[샘플 방 보기]** 클릭.
4.0 × 2.5 × 3.0 m 합성 방이 뜨고, **문은 빨강 / 창문은 하늘색**으로 보입니다.
**[거리 측정]**을 누르고 문 양쪽 모서리를 클릭하면 `0.90 m`가 나옵니다.

> ⚠️ `index.html`을 파인더에서 더블클릭해 `file://`로 여는 방식은 브라우저가
> ES 모듈 로딩을 막아서 실패할 수 있습니다. 위 한 줄짜리 http 서버를 쓰세요.

## 실제 스캔 결과 보기

**A. 서버 없이** — 아이폰에서 꺼낸 `scene_mesh.ply`와 `scene_mesh_faces_class.bin`을
**둘 다 함께** 창에 드래그&드롭 (또는 [파일 열기]에서 둘 다 선택).
`.ply`만 넣어도 문은 빨갛게 보이지만, `.bin`을 같이 넣어야 **분류별 On/Off 토글**이 살아납니다.

**B. 서버 연동** — 엔드포인트 3개가 필요합니다 (`docs/server_changes.md` 5번):

| | |
|---|---|
| `GET /viewer` | 이 페이지 |
| `GET /sessions` | `[{"session_id":"...","has_mesh":true}, ...]` |
| `GET /session/{id}/file/{name}` | 파일 원본 |

붙으면 좌측 상단 드롭다운에서 세션을 골라 바로 열 수 있습니다.

## 조작

| | |
|---|---|
| 드래그 | 회전 |
| 휠 / 핀치 | 확대 |
| `⇧` + 드래그 | 이동 |
| 분류 항목 클릭 | 해당 분류 숨기기/보이기 (예: 천장을 꺼서 위에서 내려다보기) |
| 거리 측정 | 두 점 클릭 → 미터 단위 거리 |

## 색 규약

`MeshExporter.swift`의 `classPalette`와 **완전히 같아야 합니다.**
한쪽만 고치면 색은 맞는데 라벨이 어긋나는, 가장 알아채기 어려운 버그가 납니다.

| 값 | 분류 | 색 |
|---|---|---|
| 0 | 미분류 | 회색 `130,130,130` |
| 1 | 벽 | 아이보리 `200,200,190` |
| 2 | 바닥 | 녹색 `90,140,90` |
| 3 | 천장 | 청색 `90,110,180` |
| 4 | 테이블 | 주황 `200,150,60` |
| 5 | 좌석 | 보라 `180,90,180` |
| 6 | 창문 | 하늘색 `90,200,220` |
| 7 | **문** | **빨강 `230,40,40`** |

## 파일
