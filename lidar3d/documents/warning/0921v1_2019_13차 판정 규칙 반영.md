(10차에서 본 v3의 화면 끝 조각과 같은 현상)

### 1-2. g3·g4·g5 재확인 (밝은 프레임 10개, 서로 다른 시점)

| 조각 | 판독 |
|---|---|
| g4 | **의자 등받이** — 청록색 의자 윤곽을 그대로 따라간다 (f181·f207·f210·f216·f222·f233) |

**셋 다 인물 B가 아니다.**

여기서 하나 알게 된 것: **g5의 적중률 48.2%는 사람이라서가 아니다.**
쿠션이 인물 A 바로 옆에 있어 **투영이 A의 마스크 안에 떨어진다.**
적중률은 "사람 근처에 있음"에 오염된다. 단독 지표로 쓰면 안 된다.

### 1-3. 결론

**B = 확인 불가.**

다만 **사람 조각이 될 수 없는 이유는 규명됐다**:
- 고신뢰 인스턴스 281개가 전부 g0·g1·g2로 설명되고 **남는 것이 없다**
- 저신뢰까지 내려가도 B에 해당하는 **검출 집단이 없다** (실제 인물은 75~139개를 남긴다)
- 즉 **B는 YOLO가 어떤 신뢰도로도 꾸준히 검출하지 못했다**

**검출이 없으면 검출 기반 규칙은 B를 살릴 수 없다.** 이번 반영으로 해결되지 않는다.
영상에서 B의 위치를 특정해 장면 메시 형상 유무를 확인하는 것은 **하지 못했다** — 미해결.

## 4. 반영

### 통과 판정

| 조건 | 결과 |
|---|---|
| 1: B 위치 특정 또는 사람 조각이 될 수 없는 이유 규명 | **규명됨** (검출 집단 자체가 없음) — 위치는 **확인 불가**, 미해결로 명시 |
| 2: 일관된 기준으로도 20% 재분류가 정답 인물을 안 밀어냄 | **통과** (천장 28.9%) |
| 3: 비율 임계가 v1 g0(단독)과 v3 g0(뭉침)을 가름 | **통과** (6.9% vs 22.4%, 임계 10%) |

### 바뀐 파일

| 파일 | 내용 |
|---|---|
| `scripts/stage1_masks.py` | 인스턴스별 마스크·신뢰도를 `person_instances.npz`로 저장 (4차에서 소실되던 정보) |
| `scripts/stage2_fuse.py` | 판정 규칙 (a)(b) 적용 |

**되돌리기: `LIDAR_PERSON_RULE=legacy`** 환경변수 하나로 예전 동작으로 돌아간다.
실측 확인 — v3에서 legacy로 돌리면 **5명 / 확인 필요 2개**로 반영 전과 정확히 같다.
`person_instances.npz`가 없어도 자동으로 예전 동작이 된다 (선택적 입력).

### 규칙

```
(a) 동시 검출 비율 = (동시 2개 이상 프레임) / (1개 이상 덮는 프레임)
      >= 0.10  → 층 분리 배정 (반경 제한 없음 — 몸 일부를 잃지 않기 위해)
      그 외 1개+ → 사람 인정, 크기 필터 면제
      0개        → 기존 크기 필터
(b) 뒷받침 0개 + 투영 적중률 < 20% → "확인 필요" (삭제 아님)
```

### 반영 중 고친 것

층 분리에서 삼각형(23만) × 군집점(10만) 거리 행렬을 통째로 만들어 **v3가 멈췄다.**
KD-트리 최근접으로 바꾸고 군집 점을 2만 개로 균등 추출했다.
(처음 v3 실행이 조용히 끝나 persons.json이 옛것으로 남아 있었다 — 결과를 두 번 확인해 찾았다.)
