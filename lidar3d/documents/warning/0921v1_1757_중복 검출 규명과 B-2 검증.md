## 1. 정정 — 6차 진단이 틀렸다

> 6차: "사람이 움직이며 생긴 관측을 cannot-link가 막았다"
>
> **실제**: 누운 사람은 거의 움직이지 않는다. 갈라짐은 **한 프레임 안에서** 일어났다.
> 원인은 **같은 사람의 중복 검출**이다.

### A-2. 결정적 증거 — 프레임 398

```
인스턴스 4개, 신뢰도 [0.82, 0.71, 0.24, 0.17]

  0↔1: IoU 0.022  포함비율 0.052   conf 0.82/0.71   ← 별개
  1↔3: IoU 0.589  포함비율 0.993   conf 0.71/0.17   ← 같은 사람!
  나머지 쌍: IoU 0.000
```

**인스턴스3(conf 0.17)이 인스턴스1(conf 0.71) 안에 99.3% 들어 있다.**
cannot-link가 이 둘을 "다른 사람"으로 강제해 3D 조각을 찢었다.

### A-1. 겹침 분포는 뚜렷이 갈린다 (856쌍)

| | 중앙 | 75% | 90% | 최대 |
|---|---|---|---|---|
| IoU | 0.003 | 0.313 | 0.630 | 0.932 |
| **포함비율** | **0.011** | **0.913** | 0.993 | 1.000 |

```
IoU>0.3 인 쌍      : 221 (25.8%)
포함비율>0.9 인 쌍 : 220 (25.7%)
```

**쌍의 약 1/4이 사실상 같은 사람의 중복이다.** 두 무리 사이가 비어 있어
임계값을 그 골짜기에 두면 된다.

### A-3. 중복은 한쪽이 저신뢰다

| 구분 | 쌍 | 낮은쪽 conf 중앙 | 낮은쪽 <0.3 비율 |
|---|---|---|---|
| IoU>0.2 (중복 의심) | 260 | **0.21** | **77.3%** |
| IoU≤0.05 (별개) | 518 | 0.24 | 65.3% |

### A-4. 신뢰도 하한을 올리면 인스턴스 수가 정답에 맞는다

```
전체(conf≥0.15)  : 3 초과 프레임 66/531 (12.4%)  최대 7개
conf≥0.3         : 3 초과 프레임  8      ( 1.5%)
conf≥0.5         : 3 초과 프레임  0      ( 0.0%)   ← 정답 3명과 모순 없음
```

## 2. B. 두 방식 비교

| | 6차 (원본) | B-1 중복 병합 | **B-2 신뢰도 0.5** |
|---|---|---|---|
| 인스턴스 관측 | 946 | 695 | **481** |
| 군집 / 안정 군집 | 32 / 16 | 21 / 8 | **7 / 4** |
| 조각 3이 나뉜 수 | 9 | 5 | **3** |
| 세장비 최대 | 1.8 | 1.8 | 1.5 |
| 미배정 | 0.0% | 0.0% | 0.0% |

### B-1 임계값 근거

포함비율 **0.70**. 실측 분포에서 중앙 0.011과 75분위 0.913 사이가 비어 있고,
0.70이 그 골짜기에 있다. (union-find로 같은 프레임 내 중복을 하나로 병합)

### B-2가 더 낫다

중복 병합(B-1)은 겹치는 것만 합치지만, 신뢰도 하한(B-2)은
**겹치지 않는 저신뢰 오검출까지** 걸러낸다. 결과적으로 군집이 4개로 정리됐다.

## 3. 판정 기준 대비 — 4/5 통과

기준은 실행 **전에** 확정했고 결과를 보고 바꾸지 않았다.

| 기준 | B-2 결과 |
|---|---|
| 조각 3이 **3개**로 분리 (필수) | ✅ **3개** — 정답과 일치 |
| 각 조각이 누운 사람 크기 (**세장비 ≥3**) (필수) | ❌ **1.2 / 1.5 / 1.2** |
| 가림 투영에서 **서로 다른** 인스턴스를 덮음 (필수) | ✅ **모든 인스턴스가 정확히 1개씩** |
| 5차에서 분리됐던 1명 유지 (필수) | ✅ 군집1이 대응 |
| 미배정 0% 유지 | ✅ **0.0%** |

### 투영 검증 (신뢰도 0.5 이상 인스턴스만)

```
프레임 419
  인스턴스0(conf0.92): 조각1 52.0%   → 10%↑ 1개
  인스턴스1(conf0.83): 조각2 57.2%   → 10%↑ 1개
  인스턴스2(conf0.73): 조각3 50.1%   → 10%↑ 1개
```

**세 사람이 세 조각에 깔끔히 대응한다.** 6차에서는 한 사람이 두 조각에
~20%씩 갈렸었다.

### 세장비 실패에 대한 관찰

조각들이 1.90×1.56m처럼 **정사각형에 가깝다.** 사람만이라면 1.8×0.5가 나와야 한다.
**매트가 함께 붙어 있기 때문**으로 보인다.

> 이는 **배정 문제가 아니라 융합 문제**다. 3D 배정은 사람 단위로 정확해졌으나
> (투영 검증 통과), 각 조각에 매트가 딸려 온다.
> **별도 진단이 필요하다.** 기준은 정한 대로 실패로 기록한다.

## 5. 확인 불가 / 남은 과제

- **세장비 미달의 원인** — 매트 혼입으로 추정하나 검증하지 않았다
- **v2의 `review_blob_01`이 누운 사람인지** — 미확인
- **신뢰도 0.5가 적절한 하한인지** — v3에서 정답과 맞았을 뿐,
  다른 장면(멀리 있는 사람, 어두운 곳)에서 놓칠 위험이 있다.
  **부상자를 놓치는 비용이 크므로 하한을 올리는 것은 신중해야 한다**
- B-2는 **파이프라인에 반영하지 않았다**
