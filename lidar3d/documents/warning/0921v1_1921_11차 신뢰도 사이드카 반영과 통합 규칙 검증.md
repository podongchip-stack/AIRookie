## 1. 마스크 신뢰도 사이드카 — **반영 완료**

### 바뀐 파일

| 파일 | 내용 |
|---|---|
| `scripts/stage2_fuse.py` | 신뢰도 계산 + `fused_person_NN_confidence.bin` 저장 |
| `server/viewer/index.html` | 사이드카 로드, 이중 검증, 회색 혼합 셰이더, 토글 |
| `server/app.py` | `PERSON_FILE_RE`에 `_confidence.bin` 허용 |

> **중요한 정정**: 10차 4-4절은 "삭제 철회"로 적었으나, **파이프라인에는 애초에 삭제 코드가 없었다.**
> 9차의 삭제는 진단 스크립트(`mask_consistency.py`)에서만 한 실험이었다.
> 따라서 이번 변경은 **제거가 아니라 추가**뿐이고, 그래서 판정이 전혀 바뀌지 않는다.

### 사이드카 형식 (10차 3-1 그대로)

```
<메시이름>_confidence.bin
  [0:4]   "LCF1"
  [4:8]   uint32  정점 수 N
  [8:16]  uint64  좌표 해시 (FNV-1a, 앞뒤 1000정점의 float32 비트)
  [16: ]  float32 × N   신뢰도 0.0~1.0 (PLY 정점 순서)
```

- 5프레임 미만으로 보인 정점은 근거가 부족하므로 **1.0(감점 없음)** 으로 둔다.
- Open3D는 좌표를 `double`로 쓰지만 three.js는 `Float32Array`로 읽는다.
  파이썬에서 `float32`로 내림해 해싱하므로 **양쪽 비트가 일치한다.** (실측 확인)

### 재실행 결과 — 판정 불변

```

v2  사람 6→6   확인 필요 1→1   동일
v3  사람 5→5   확인 필요 2→2   동일
```

사이드카 10개 생성. 왕복 검증(정점 수·해시·길이) **전부 일치**.

   - 다시 누르면 원래대로 돌아온다.
5. **실패 징후**: 모델이 새까맣게 되거나 아예 안 보이면 셰이더 주입이 깨진 것이다.

   통째로 죽은 적이 있어, 구문 검사만으로는 믿지 않는다.)

## 2. 크기 필터 면제 단독 적용의 위험 — **확인됨**

### 2-1. v3에서 면제만 넣으면

**그렇다. 누운 3명이 붙은 덩어리(g0 = `review_blob_01`)가 "사람 1명"이 된다.**

g0은 7.18㎡, 2.05 × 0.68 × 2.32 m로 크기 필터를 못 넘지만,
고신뢰 군집 **4개**가 뒷받침하므로 면제를 받는다.

```
현행       사람 5 / 확인 필요 2
면제 단독   사람 6 / 확인 필요 1     ← g0이 "확인 필요" → "사람 1명"
통합 규칙   사람 8 / 확인 필요 1
```

### 2-2. 정보가 나빠진다는 근거

g0이 덮는 고신뢰 인스턴스는 **312개**다 (군집별 3 / 68 / 172 / 69).
즉 **최소 3명분의 검출**이 이 덩어리 하나에 들어 있다.

| | 현행 | 면제 단독 |
|---|---|---|
| g0의 표시 | **"확인 필요"** — 사람이 눈으로 확인 | **"사람 1명"** |
| 집계되는 인원 | (세지 않음, 경고로 남음) | **1명** |
| 실제 들어 있는 사람 | 3명 | 3명 |

**"3명을 1명으로 확정"하는 것이 "모르겠으니 확인해 달라"보다 나쁘다.**
현행은 사람이 열어볼 계기를 주지만, 면제 단독은 **조용히 틀린 숫자를 확정한다.**
사용자가 정한 비대칭 비용(사람을 놓치는 쪽이 훨씬 나쁘다)에 정면으로 걸린다.

**결론: 면제 단독 반영은 권하지 않는다.** 10차에서 "2순위로 반영" 권고했던 것을 **철회한다.**

"덮는다"의 정의: 군집 c의 계층1 관측 중, 조각의 가림처리 투영이 그 인스턴스 마스크를

| 세션 | 조각 | 크기 | 근거 군집 | 관측 수 |

**v3는 맞다.** g0을 3조각으로 나눠 누운 3명이 각각 별개로 인정된다.
(군집0은 관측 3회로 문턱에 걸쳤을 뿐이고, 실제로는 조각을 만들 만큼의 정점을
가져가지 못해 최종 조각은 3개다.)

### v1에서 걸린 이유 — **군집이 사람이 아니라 시간으로 쪼개졌다**

```
군집0: 관측 93  중심 ( 1.15,-0.22, 0.29)  프레임   0~232
군집1: 관측 81  중심 ( 1.45, 0.14, 0.50)  프레임 164~516
군집2: 관측 89  중심 ( 1.61, 0.07, 0.35)  프레임 292~529

군집0-1  0.51m     군집0-2  0.54m     군집1-2  0.23m
```

**세 군집의 중심이 0.23~0.54 m 안에 몰려 있고, 프레임 구간이 순차적으로 이어진다.**
한 사람이 촬영 내내 조금씩 움직인 것을, 반경 0.374 m 클러스터링이
**시간 순서대로 3토막 낸 것**이다.

뒷받침: v1은 **고신뢰 인스턴스가 2개인 프레임이 354개 중 25개뿐**이다(0개 106, 1개 223).
대부분의 프레임에 사람이 한 명만 잡힌다.

그래서 g0(한 사람)이 "군집 3개가 덮는다"로 판정돼 셋으로 쪼개지고,
같은 사람을 여러 조각이 동시에 덮으므로 3+가 260건(95.6%)이 된다.

### 판정 기준 대조

| 기준 | 결과 | 판정 |
|---|---|---|
| v1: 1:1 대응 ≥ 99.3%, 사람 수 3 | **4.0%, 5명** | ❌ |
| v2: 현행과 동일하거나 개선 | 완전히 동일 | ✅ |
| v3: 누운 3명 각각 인정 | 3조각으로 인정 | ✅ |
| v3: 놓침 0% | **0.0%** (현행 64.4%) | ✅ |
| 모든 세션: 놓침이 현행보다 늘지 않음 | v1 0%, v2 2.1%, v3 0% — 전부 동일 이하 | ✅ |

**v1 기준 하나 때문에 통합 규칙도 그대로는 반영할 수 없다.**

문제는 규칙이 아니라 **군집 자체**다. 군집이 사람 수를 세지 못하면
군집 수에 기대는 어떤 규칙도 맞을 수 없다. 반경 0.374 m 를 시간축과 함께
다루는 방법(예: 프레임 구간이 겹치지 않으면 합치기)이 필요하지만
**검증하지 않았다.**

## 4. 무근거 저적중 조각의 재분류

### 4-2. 임계값 근거

v1~v3 통합 규칙 "사람" 조각 19개의 적중률을 모두 줄세웠다.

```
근거 있음 :  45.6  59.3  60.4  62.6  69.2  74.4  75.7  86.7
근거 없음 :   8.0  13.1  14.9  15.6  18.8  27.4  28.3  37.3  43.6  52.1  63.3
```

- **근거 있는 조각의 최솟값은 45.6%** — 그 아래여야 한다.
- 근거 없는 쪽에서 가장 큰 틈은 **18.8 → 27.4 (8.6%p)** 다.

따라서 **임계 20%** 로 정한다. 관측된 틈에 놓았을 뿐이고,
**표본이 19개라 근거가 약하다.**

### 4-1. 옮겨지는 조각

| 세션 | 조각 | 적중률 | 크기 |
|---|---|---|---|
| v3 | g6 | 8.0% | 0.61 × 0.41 × 0.46 m |

| v2 | g2 | 14.9% | 1.10 × 0.76 × 0.82 m |

**5개** (v3 4개, v2 1개, v1 0개). v1은 최저가 37.3%라 하나도 옮겨지지 않는다.

### 4-3. 영상 확인

각 조각이 가장 잘 보이는 프레임에 투영해 확인했다.

| 조각 | 프레임 | 덮고 있는 것 |
|---|---|---|
| v3 g2 | 378 | 침구·매트·바닥 |
| v3 g3 | 725 | 침대 위 이불 |
| v3 g4 | 285 | 책상 위 물건 |
| v3 g6 | 356 | 천장·벽 |
| v2 g2 | 131 | 책상 위 잡동사니 |

**사람으로 보이는 것은 없었다.**

> ⚠️ **한계**: 조각마다 **가장 잘 보이는 프레임 한 장씩만** 봤다.
> 장면이 어두워 판독이 쉽지 않다. "사람이 전혀 없다"고 확정하지는 못한다.
> 5개 전부를 여러 프레임으로 다시 보는 것이 안전하다.

참고로 임계 바로 위의 v2 g3(28.3%)·g4(27.4%)도 책상 위 물건으로 보였다.
**임계 20%는 보수적인 쪽이다** — 사람이 아닌 것을 일부 놓아준다.
비대칭 비용상 그 방향이 맞다.

### 4절 판정

옮겨지는 5개 중 **실제 사람으로 보이는 것은 확인되지 않았다.**
다만 재분류는 "삭제"가 아니라 **"확인 필요"로 옮기는 것**이라,
틀려도 사람이 눈으로 되찾을 수 있다. 위험이 낮은 변경이다.

- v1 / v2의 **정답 인원 수가 여전히 미확정**이다. v1은 현행 3명이 대응 99.3%로
  맞아 보이지만, 위 군집 분석은 **사람이 사실상 1명**임을 시사한다. **모순이 남아 있다.**
  촬영자 확인이 필요하다 — *v1에 사람이 몇 명 있었는가?*
- 반경 0.374 m 는 여전히 **관측 13개 기반**이다.
- 4절 임계 20%는 **조각 19개 표본**에서 나왔다.
- 4-3 영상 확인은 **조각당 한 프레임**뿐이다.
