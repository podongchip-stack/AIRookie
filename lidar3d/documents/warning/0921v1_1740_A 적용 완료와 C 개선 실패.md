## 2. C 개선 — 실패

### 세 가지를 보완했다

| 항목 | 5차 | 6차 |
|---|---|---|
| C-1 군집화 | flood-fill (연쇄 발생) | **동시 출현 제약(cannot-link)** |
| C-2 배정 | 군집 **중심점**까지 거리 | **군집 점들 중 최근접 점** |
| C-3 반경 | 0.25m (근거 없음) | **0.374m** (군집14 실측 흩어짐 ×2) |

### 판정 기준 대비 — 핵심 기준 실패

| 기준 | 결과 |
|---|---|
| 조각 3이 **3개**로 분리 | ❌ **9개로 과분할** (안정 군집 16개) |
| 각 조각이 누운 사람 크기 (길이 1.5~2.0, 폭 0.4~0.6, **세장비 3 이상**) | ❌ **세장비 최대 1.8** |
| 가림 투영에서 각 조각이 **서로 다른** 인스턴스를 덮음 | ❌ 인스턴스 절반이 **2개 조각에 걸침** |
| 미배정 비율 < 14.8% | ✅ **0.0%** |
| 이미 분리된 1명(군집14)이 나빠지지 않음 | ❌ 해당 조각 소멸 |

### C-2는 성공했다

```
가장 가까운 군집 점까지: 중앙 0.003m  90% 0.008m
30cm 초과 미배정: 0.0%   (5차 중심점 기준은 14.8%)
```

5차의 "중심점까지 중앙 0.73m"와 비교하면 배정 정확도는 크게 올랐다.
**배정 방식 자체는 옳다.**

### C-1이 실패 원인이다

동시 출현 제약이 연쇄를 막은 것은 맞다. 그러나 **사람이 움직이며 생긴 관측들까지
잇지 못하게 막았다.** 안정 군집이 3개가 아니라 **16개**가 됐고,
한 사람이 여러 군집으로 흩어졌다.

가림 투영이 이를 보여준다 (프레임 398):

```
인스턴스0: 조각2 50.9%                    → 10%↑ 덮은 조각 1개  (깨끗)
인스턴스1: 조각7 18.7%  조각4 13.4%       → 10%↑ 덮은 조각 2개  (갈라짐)
인스턴스2: 조각1 59.5%                    → 10%↑ 덮은 조각 1개  (깨끗)
인스턴스3: 조각7 21.1%  조각4 20.7%       → 10%↑ 덮은 조각 2개  (갈라짐)
```

한 사람이 조각7과 조각4로 **각각 ~20%씩 갈렸다.**

### C-3 반경 — 근거는 갖췄으나 한계가 있다

```
군집14 실측 흩어짐 (0.05, 0.10, 0.15) m
→ 3축 결합 표준편차 0.187m
→ 반경 = 그 2배 = 0.374m
```

> ⚠️ **한계**: 군집14는 **관측 13회뿐**이다. 표본이 적어 흩어짐이 과소평가됐을 수 있다.
> 이전 0.25m는 근거 없는 값이었으므로 개선이지만, 이 값도 확정적이지 않다.

## 3. 진단 — 두 요구가 충돌한다

C가 실패한 구조적 이유:

| 요구 | 필요한 동작 |
|---|---|
| 같은 프레임의 인스턴스는 **다른 사람** | 떼어놓아야 한다 (cannot-link) |
| 다른 프레임의 같은 사람은 **같은 사람** | 이어야 한다 (추적) |

**지금은 앞만 강제해서 뒤가 깨졌다.** 5차는 반대로 뒤만 해서 앞이 깨졌다
(flood-fill 연쇄로 2명이 한 군집).

빠진 것은 **시간축 연속성**이다. "인접 프레임에서 가까운 관측은 같은 사람"이라는
정보를 쓰지 않았다.

> 이것은 4차 진단 D절에서 "라벨맵 방안의 가장 큰 미검증 위험"으로 적어둔
> **프레임 간 추적 문제**가 실제로 터진 것이다.

### 다음 시도의 방향 (미검증)

프레임 순서를 따라 관측을 잇되, **같은 프레임에서 충돌할 때만 분기**하는 방식.
즉 추적을 기본으로 하고 cannot-link를 예외 처리로 쓴다 — 지금은 반대로 했다.
