## 결론 — **(c) 부분 원인**

stale 마스크는 **웅크린 사람의 원인이 맞다. 누운 사람의 원인은 아니다.**

| 조각 | 현행 | 신선한 마스크만 | 판정 |

| 웅크린 사람 | 3.88㎡ **2.59**×1.45×1.89m ❌ | 2.20㎡ **1.28**×1.39×1.08m **✅** | **stale이 원인** |

누운 사람은 stale 마스크를 제거해도 깊이가 **2.36 → 2.51m로 오히려 늘었다.**
별도 원인이 있고 아직 규명하지 못했다.

## A-1. `last` 변수의 갱신 — **(a) 이전 마스크 재사용**

`scripts/stage2_fuse.py`:

```python
bg,ob=mk(BGV),mk(OBV); nb=no=0; last=np.zeros((H,W),bool)   # 54행 초기화
for r in rows:
    ...
    vfi=int(r["video_frame_index"])
    if vfi in masks: last=masks[vfi]                         # 66행 — 있을 때만 갱신
    ...
    db=d.copy(); db[last]=0                                  # 72행 배경에서 제외
    do=d.copy(); do[~last]=0                                 # 75행 객체는 마스크만
```

`masks`의 키는 0 이상이므로 **`vfi < 0`이면 절대 갱신되지 않고 직전 마스크가 그대로 쓰인다.**
스킵도, 마스크 없음 처리도 아니다.

## A-4. `video_frame_index < 0`이 50%인 이유 — **정상 동작**

`iphone/LiDAR_Space3D/ARCaptureManager.swift`:

```swift
var writtenFrameIndex = -1                                       // 450행
let videoInterval = videoSaveHz > 0 ? 1.0/videoSaveHz : .infinity
if lastVideoWriteTime < 0 || (t - lastVideoWriteTime) >= videoInterval {
    ...
    writtenFrameIndex = videoFrameCount                          // 461행
}
...
let depthInterval = 1.0 / depthSaveHz                            // 501행
if lastDepthWriteTime < 0 || (t - lastDepthWriteTime) >= depthInterval {
    writeDepth(..., videoFrameIndex: writtenFrameIndex)          // 505행
}
```

**영상과 뎁스가 서로 다른 주기 게이트를 통과한다.**
뎁스 주기에는 걸리고 영상 주기에는 안 걸리면 `-1`이 기록된다.

실측: `0, -1, 3, -1, 6, -1, 9, -1 ...` 로 규칙적이다.
뎁스 531프레임 / 영상 796프레임, 유효 인덱스 266개 × 3 ≈ 798. **녹화 누락이 아니다.**

### C-1. 덩어리별 경계상자

`scripts/export_detection_overlay.py` — `boxes` 배열 추가:

```python
boxes = []
for poly in polys:
    xs = [q[0] for q in poly]; ys = [q[1] for q in poly]
    boxes.append([min(xs), min(ys), max(xs), max(ys)])
# bbox(합집합)는 이전 형식 호환을 위해 남겨 둔다
frames[key] = {"polys": polys, "boxes": boxes, "bbox": [...], "n": len(polys)}
```

`server/viewer/detect.html` — 덩어리마다 박스를 그리고 `person 1`, `person 2` 로 표기.

## D. 확인 불가 / 남은 과제

- **누운 사람이 넓어지는 원인** — stale 마스크가 아니다. 미규명
- **H2**(일부 프레임만 기여) — TSDF가 정점별 기여 프레임을 기록하지 않아 계측 코드 없이는 검증 불가
- **정답 인원** — 영상만으로 중복 제거 실패
- 다른 세션에서 stale 마스크 비율이 같은지 — `v3`만 측정했다

## E. 깊이 게이트 수정을 검토할 때의 참고

stale 마스크를 없애도 **누운 사람은 여전히 탈락**하므로, 그것만으로는 부족하다.
다만 두 가지는 분리해서 판단해야 한다.

| 후보 수정 | 기대 효과 | 위험 |
|---|---|---|
| stale 마스크 사용 중단 | 웅크린 사람 회복 | 융합 프레임이 457→229로 **절반**. 표면적 15.23→11.59㎡ 감소 |
| 깊이 게이트 조정 | 누운 사람? (미검증) | 과거 실패 재발 가능 — 사람 여럿일 때 양쪽 잘림 |

stale 마스크를 끄면 데이터의 절반을 버리게 된다.
**마스크를 버리는 대신 포즈로 보정(reprojection)하는 방법**도 후보다 — 다만 미검증이다.
