# spider — 거미줄 분배 모델 (실험실)

병원을 3차원 공간의 점으로 두고(x·y 지리, z 역량), 환자가 자기 높이 이상의 병원에 줄(거미줄)을 걸어
가장 짧은 줄을 잡는 분배 모델이다. 여러 환자가 같은 시간 창에 같은 병원을 잡으면 충돌이고, 덜 위급한
쪽이 **이동 중 위치에서** 다른 줄로 비킨다(재전원과 같은 동작). RVO2(속도 장애물·상호 회피)와
Mitzenmacher의 "낡은 정보로 고르면 몰린다"에서 착안했다. 2026-10-10~11 설계.

**지금은 hub와 연결되지 않은 독립 실험 폴더다.** 다른 폴더의 파일을 수정하지 않는다(`sim/`과 같은 원칙).
읽기만 하는 것: `info/Hospital_inform/info/data/snapshots_nationwide/*.jsonl`(E-Gen 스냅샷),
`info/.../data/hira/specialists.json`(심평원 전문의 수).

## 열어 보기

`map.html`을 브라우저로 연다(로컬 파일 그대로, 인터넷은 deck.gl·MapLibre·지도 타일 때문에 필요).
같은 폴더에 `roads_data.js`(25.8 MB)와 `hospitals_xyz.json`이 있어야 한다.

- 병원 530곳이 역량 높이에 뜬 노드로 보이고(병상 데이터 없는 114곳은 바닥의 빈 원), 환자는 발생 시각에
  켜져 **브라우저 안에서 계산한 실제 도로 최단경로**를 따라 흘러간다. 공중엔 환자 점 → 병원 점 직선 거미줄.
- 시나리오 5개 + 직접 구성 + 완전 랜덤(서울 도로 위 / 전국 병원 주변, KTAS 분포 3종).
- 시계로 재생·되감기. 충돌한 병원은 붉은 고리, 점유 중은 파란 고리, 비킨 줄은 회색.
- 시점 버튼(전국·서울·위·옆·회전)과 재생 때 카메라 연출. 마우스로 잡으면 즉시 멈춘다.

## 모델 (초안 — 숫자는 전부 전문의 검토 전)

```
줄 길이 = 도로 분 − μ(KTAS) × 올라가는 이득          (유효 역량 ≥ 필요 역량)
        = 도로 분 + ν(KTAS) × 모자란 양               (유효 역량 < 필요 역량, 0.75 넘게 모자라면 줄 없음)
유효 역량 = 등급(1~4) + 전문의 두께(≤1명 −0.4, ≤3명 −0.2, ≥8명 +0.2)
          + 야간(22~06: 얇은 지역기관 −0.6, 그 외 −0.1~−0.25) − 포화도×0.3 − 창 부하×0.25
필요 역량 = KTAS 1→4, 2→3, 3→2, 4·5→1
μ = K1·2 30분/레벨, K3 5분, K4·5 −λ(5분, 센터 회피) · 이송 중 중증 10명이면 0까지 감쇠
ν = 30 / 15 / 5분
벽(질환군) = 심근경색→혈관조영, 뇌졸중→CT, 중증외상→센터 이상
충돌 = 도착 시각이 τ(10분) 안에 겹치는 환자가 한도(2)를 넘거나 병상(가용−우리 점유)이 없음
양보 = KTAS 낮은 숫자가 남고, 같으면 먼저 닿는 쪽. 이미 도착한 환자는 안 밀림. 비킨 병원엔 다시 안 걸림
```

2026-10-11 전국 무작위 200명 × 시드 3으로 잰 것: 낮에는 KTAS 2의 권역 비율이 두 배(이동 +1~2분),
KTAS 3는 얇은 지역기관의 1/3이 몇 분 거리 센터로. 밤에는 얇은 지역기관으로 가는 KTAS 3가 0이 되고
이동이 7~12분 는다. 초과(빈 벽 없음)는 240명까지 0. 환자당 계산 약 30 ms.

## 파일

| 파일 | 역할 |
|---|---|
| `make_map.py` → `map.html` | 화면 + 엔진(JS). 바꾸면 다시 생성 |
| `build_xyz.py` → `hospitals_xyz.json` | 스냅샷 최신 폴링에서 전국 병원 x·y·z·장비·병상·전문의 수. z = 등급 + 중증 신고 비율 |
| `build_roads_kr.py` → `roads_data.js` | OSM 남한 pbf → 도로 그래프(전국 3차로 이상 + 병원 4 km 안 골목, 15 m 단순화, 노드 100만). pbf는 `data/`에 두고 커밋 안 함 |
| `fatigue_probe.py` → `fatigue_probe.json` | 의사 피로도 대리 지표(6시간 수용 ÷ 응급의학 전문의) 분포. 결론: 편차는 병원 사이(15배), 한 병원 안은 1.75배 |

재생성: `conda activate rookie_info`, Windows는 `PYTHONUTF8=1`. 도로 그래프는 `pip install osmium` 후 pbf 다운로드, 약 70초.

## 주의

- 경로는 OSM 자유흐름 속도(등급별 80/55/45/35/25 km/h) 기반이라 실제 ETA가 아니다. 탐색은 120분에서 끊는다.
- 거리 계산에서 `dist`는 Float64여야 한다. Float32면 길이 0 간선에서 선행자 고리가 생겨 무한루프(실제 겪음).
- 지도 타일: CARTO는 API 키 필요, OSM 본서버는 file://에서 Access blocked. Esri 공개 타일(기본)·openstreetmap.de만 키 없이 된다.
- MapLibre 기본 최대 기울기 60° — deck.gl과 어긋나 기둥이 미끄러진다. `setMaxPitch(85)`로 맞춰 둠.
- RoutingKit은 쓰지 않는다. 보여주는 방식만 참고했다가 그것도 뺐다.
